Native macOS menu bar authenticator for Apple Silicon, macOS 14 or later.

- Full view by default, with search and account import controls.
- Optional simplified view in the right-click menu.
- Balanced account-list spacing and reliable popup sizing.
- English and Simplified Chinese setup guides.

Download **MacAuthenticator-arm64.zip**, unzip it and move the app to **Applications**. Open the app from the menu bar key icon.

应用默认显示完整视图，可通过右键菜单切换精简视图。下载 ZIP 并解压，将应用拖入“应用程序”，然后点击菜单栏钥匙图标即可使用。

The app is ad-hoc signed. For the first launch, use **System Settings → Privacy & Security → Open Anyway** if prompted.
